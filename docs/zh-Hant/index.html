小滿記 · 幫助與支持

小滿記是一款簡單溫柔的習慣打卡和日記 App：每天點亮幾個小習慣，寫幾句日誌和筆記，日子慢慢就滿了。

常見問題

資料儲存在哪裡？
全部儲存在你的手機上，我們沒有伺服器。可以在「我的 → 備份」裡匯出備份。

換手機怎麼辦？
用 iPhone 自帶的整機遷移或 iCloud 雲備份，資料會一起帶過去；也可以在舊手機匯出備份，新手機匯入。

會員怎麼恢復？
在「我的 → 開通會員」裡點「恢復購買」，使用同一個 Apple ID 即可找回。

怎麼取消自動續費？
iPhone「設定 → Apple ID → 訂閱」裡關閉即可。
