小满记 · 帮助与支持

小满记是一款简单温柔的习惯打卡和日记 App：每天点亮几个小习惯，写几句日志和笔记，日子慢慢就满了。

常见问题

数据保存在哪里？
全部保存在你的手机上，我们没有服务器。可以在「我的 → 备份」里导出备份。

换手机怎么办？
用 iPhone 自带的整机迁移或 iCloud 云备份，数据会一起带过去；也可以在旧手机导出备份，新手机导入。

会员怎么恢复？
在「我的 → 开通会员」里点「恢复购买」，使用同一个 Apple ID 即可找回。

怎么取消自动续费？
iPhone「设置 → Apple ID → 订阅」里关闭即可。
